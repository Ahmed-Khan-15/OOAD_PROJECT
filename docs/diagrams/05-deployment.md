## Assumptions / gaps

- Railway service state is user-reported, not inspectable from this repository. Region, runtime health, current variable values, and domain routing are not verified here.
- Vercel project root is intended to be `frontend`; `DEPLOYMENT.md` documents that setting. Actual production build details depend on dashboard configuration.
- `Dockerfile` starts the API with `--server.port=${PORT:-8081}`. Java runtime is 21. PostgreSQL server major version is hosting configuration, not pinned by this repo.
- No `docker-compose.yml`, Kubernetes manifests, Terraform, Railway config, Vercel `vercel.json`, or secrets are present in the checked-in files.
- The local verification report is not proof that Railway currently contains the local observation rows. A separate protected import/restore is necessary.
